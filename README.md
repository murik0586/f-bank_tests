## Запуск тестов локально

**1. Запустить сервис (отдельный терминал)**
```bash
cd dist
python -m http.server 8000
```

*Оставь этот терминал открытым.*

**2. Установить зависимости (второй терминал)**
```bash
cd dist/tests
pip install -r requirements.txt
```
**3. Запустить автотесты (второй терминал)**
```bash
python -m pytest test_transfer.py -v

```

## Вывод

Продукт **НЕ ГОТОВ к релизу**. Обнаружены критические дефекты:

- Приём отрицательных сумм

**Рекомендации:** исправить расчёт комиссии, добавить валидацию всех полей, ограничить переводы только рублёвым счётом.
