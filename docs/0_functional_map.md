## 1. ОБЩЕЕ ОПИСАНИЕ

F-Bank — учебный банковский сервис для осуществления рублёвых переводов.

**URL:** `http://localhost:8000/?balance=30000&reserved=20001`

    Элемент	                   Как найти	                     Что делает
    Блок «Рубли»	        Карточка с текстом	         Открывает меню перевода
    Блок «Доллары»	        Карточка с текстом	            ? (НАЙДЁМ БАГ)
    Блок «Евро»	            Карточка с текстом	            ? (НАЙДЁМ БАГ)
    Поле «Номер карты» 	    input с placeholder	              Ввод 16 цифр
    Поле «Сумма перевода»	input с default 1000   	             Ввод суммы
    Кнопка «Перевести»	    button с текстом	             Отправка перевода
    Текст комиссии	        span с id="comission"	         Показывает комиссию
    Текст ошибки	        span красного цвета	             «Недостаточно средств»
