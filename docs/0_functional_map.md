## 1. ОБЩЕЕ ОПИСАНИЕ

F-Bank — учебный банковский сервис для осуществления рублёвых переводов.

**URL:** "http://localhost:8000/?balance=30000&reserved=20001"

---

## 2. КАРТА ЭЛЕМЕНТОВ ИНТЕРФЕЙСА

| Элемент | Как найти | Что делает |
|---------|-----------|------------|
| Блок "Рубли" | Карточка с текстом | Открывает меню перевода |
| Блок "Доллары" | Карточка с текстом | ? (ожидается: ничего не происходит) |
| Блок "Евро" | Карточка с текстом | ? (ожидается: ничего не происходит) |
| Поле "Номер карты" | input с placeholder "0000 0000 0000 0000" | Ввод 16 цифр |
| Поле "Сумма перевода" | input с default "1000" | Ввод суммы |
| Кнопка "Перевести" | button с текстом "Перевести" | Отправка перевода |
| Текст комиссии | span с id "comission" | Показывает комиссию |
| Текст ошибки | span красного цвета | Сообщение "Недостаточно средств" |

| Валюта | Баланс | Резерв | Доступно |

| Доллары | 100 $ | 0 $ | 100 $ |
| Евро | 300 € | 26 € | 274 € |

---

## 4. БИЗНЕС-ЛОГИКА

Доступная сумма -> Баланс - Резерв

Комиссия -> Сумма перевода * 0.1 с округлением вниз

Условие перевода:
Если (Сумма перевода + Комиссия) <= Доступная сумма -> перевод возможен
Если (Сумма перевода + Комиссия) > Доступная сумма -> сообщение "Недостаточно средств"

---

## 5. ПАРАМЕТРЫ URL (изменяемые)

"http://localhost:8000/?balance=30000&reserved=20001"

    balance -> сумма на рублёвом счёте
    reserved -> зарезервированная сумма

Примеры:
"?balance=50000&reserved=10000" -> баланс 50 000, резерв 10 000
"?balance=1000&reserved=500" -> баланс 1 000, резерв 500
"?balance=0&reserved=0" -> баланс 0, резерв 0

## 6. ОЖИДАЕМЫЕ БАГИ (ПО РЕЗУЛЬТАТАМ ТЕСТИРОВАНИЯ)

| ID | Компонент | Описание |
|----|-----------|----------|
| BUG-1 | Поле карты | Пропускает 17 цифр (должно быть ровно 16) |
| BUG-2 | Сумма перевода | Перевод 0 ₽ возможен |
| BUG-3 | Комиссия | Округление работает некорректно (99 ₽ -> комиссия 0) |
| BUG-4 | Сумма перевода | Отрицательные суммы принимаются |
| BUG-5 | Комиссия | Ошибка расчёта для 9091 ₽ (900 вместо 909) |
