# Баг-репорты

## Баг-репорт №1

| Поле | Значение |
|------|----------|
| **Заголовок** | Поле ввода номера карты пропускает значение длиной 17 символов |
| **Серьёзность** | Major |
| **Приоритет** | High |
| **Шаги воспроизведения** | 1. Запустить приложение<br>2. Кликнуть по карточке «Рубли»<br>3. В поле карты ввести 17 цифр подряд (например, 11112222333344445)<br>4. Указать сумму 77<br>5. Нажать кнопку «Перевести» |
| **Ожидаемый результат** | Появляется сообщение «Номер карты должен содержать 16 цифр» |
| **Фактический результат** | Транзакция успешно выполняется с невалидным номером |
| **Окружение** | Chrome, localhost:8000 |

## Баг-репорт №2

| Поле | Значение |
|------|----------|
| **Заголовок** | Система позволяет выполнить перевод на нулевую сумму |
| **Серьёзность** | Major |
| **Приоритет** | High |
| **Шаги воспроизведения** | 1. Запустить приложение<br>2. Кликнуть по карточке «Рубли»<br>3. Ввести корректный номер карты (16 цифр)<br>4. В поле суммы указать 0 (или оставить поле пустым)<br>5. Нажать кнопку «Перевести» |
| **Ожидаемый результат** | Появляется сообщение «Сумма должна быть больше нуля» |
| **Фактический результат** | Появляется уведомление об успешном переводе 0 ₽ |
| **Окружение** | Chrome, localhost:8000 |

## Баг-репорт №3

| Поле | Значение                                                                                                                                                           |
|------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Заголовок** | Алгоритм расчёта комиссии некорректно округляет сумму                                                                                                              |
| **Серьёзность** | Major                                                                                                                                                              |
| **Приоритет** | High                                                                                                                                                               |
| **Шаги воспроизведения** | 1. Запустить приложение<br>2. Перейти в форму перевода через рублёвый счёт<br>3. Указать любую валидную карту<br>4. Ввести сумму 99 рублей                         |
| **Ожидаемый результат** | Комиссия составляет 9 ₽ (10% от 99 = 9.9 с округлением вниз)                                                                                                       |
| **Фактический результат** | Система показывает комиссию 0 ₽                                                                                                                                    |
| **Дополнительные примеры** | Сумма 1819 ₽: комиссия 180 руб (ожидается 181 руб)<br>Сумма 1714 руб: комиссия 170 руб (ожидается 171 руб)<br>Сумма 2110 руб: комиссия 210 руб (ожидается 211 руб) |
| **Окружение** | Chrome, localhost:8000                                                                                                                                             |

## Баг-репорт №4

| Поле | Значение |
|------|----------|
| **Заголовок** | Приложение допускает отправку отрицательного денежного перевода |
| **Серьёзность** | Critical |
| **Приоритет** | High |
| **Шаги воспроизведения** | 1. Запустить приложение<br>2. Кликнуть по карточке «Рубли»<br>3. Ввести корректный номер карты (16 цифр)<br>4. В поле суммы ввести отрицательное число (например, -100)<br>5. Нажать кнопку «Перевести» |
| **Ожидаемый результат** | Появляется сообщение «Сумма должна быть положительной» |
| **Фактический результат** | Транзакция на -100 ₽ успешно завершается, комиссия также становится отрицательной (-10 ₽) |
| **Окружение** | Chrome, localhost:8000 |

## Баг-репорт №5

| Поле | Значение                                                                                                                                                                                                                                          |
|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Заголовок** | Неверный расчёт комиссии для суммы 9091 ₽                                                                                                                                                                                                         |
| **Серьёзность** | Critical                                                                                                                                                                                                                                          |
| **Приоритет** | High                                                                                                                                                                                                                                              |
| **Шаги воспроизведения** | 1. Запустить приложение с параметрами balance=30000&reserved=20001<br>2. Кликнуть по карточке «Рубли»<br>3. Ввести номер карты из 16 цифр (например, 1234 5423 1543 2151)<br>4. В поле суммы ввести 9091<br>5. Посмотреть на отображаемую комиссию |
| **Ожидаемый результат** | Комиссия составляет 909 ₽ (10% от 9091 = 909.1, округление вниз = 909)                                                                                                                                                                            |
| **Фактический результат** | Система показывает комиссию 900 Руб |                                                                                                                                                                                                              |
| **Последствия** | Из-за заниженной комиссии итоговое списание = 9091+900 = 9991 ₽ (вместо 10000 ₽). Перевод проходит там, где должен быть заблокирован из-за недостатка средств.                                                                                    |
| **Окружение** | Chrome, localhost:8000                                                                                                                                                                                                                            |
